Where the page is thin, and what code can do about it

Sixteen gaps across the page and the system behind it. Repos properly help three of them: a visual library, quote checking, and leak checks. For five more, the fix is time or a decision, and no repo changes that.

Data: Metricool evolution metrics 1-25 Oct, growth-system weekly notes, performance lessons, reach batch. Nothing installed, nothing scheduled, £0.

The reel ceiling

Carousels moved the account from about 200 people a day to 5,734 on 22 Oct. Reels stayed flat. Daily reel reach has sat between 32 and 190 all month, averaging 116 per reel. Every reel is text on a Slate background, and the footage folder the engine has supported since version 1.2 is still empty.

So the first visual fix is real images behind the words: public-domain landscapes, manuscripts, maps and objects. No faces and no statues.

What no repo fixes

  • The comment agent going live: five secrets, about 20 minutes, steps already written.
  • Poll and quiz stickers: hand-post only.
  • Pillar mix: every post this week was Human Mind. That needs your pillar yes/no, not code.
  • Your time: 45 minutes a weekday and about a dozen unmerged PRs. More tools would add to that list.
