# Moodius Aurelius logo options v2 (earthy blue + green)

Four directions, each as an avatar mark (dark + light), a dark lockup and a
light lockup. Every SVG has its letters converted to outlines, so it opens
crisp anywhere without the fonts installed. `comparison.png` shows all four
side by side with the Instagram avatar at 320px and at feed size (110px).

| Option | Idea | Ground |
|---|---|---|
| A Verdigris Point | The current "M." evolved: heavier Playfair, verdigris full stop | Ink Petrol |
| B Spruce Stack | MOODIUS over italic *Aurelius*; avatar "Ma" | Deep Spruce |
| C Harbour Seal | Roundel with the name round the ring, M in the centre | Harbour Blue |
| D Horizon | M standing on a horizon: blue above (what you can't control), green below (the ground you stand on) | Ink Petrol / full-bleed avatar |

Palette: Ink Petrol #0F2229, Deep Spruce #163A31, Pine #2A5A46,
Harbour Blue #24506B, Verdigris #45B096 (#2B7F6B on light), Lichen #B3D3A0,
Mist Blue #AFCFE0, Bone #F3EFE7. Type: Playfair Display + Inter (OFL).

Nothing here replaces the live avatar, favicon or Threads marks until one is chosen.

Rebuild: `pip install fonttools uharfbuzz cairosvg pillow && python3 build_logos.py`
