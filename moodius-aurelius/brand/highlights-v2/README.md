# Highlight covers v2

Seven separate covers (1080x1920, icon centred in the highlight circle),
alternating Bone and Slate grounds so each circle stands apart; Manifesto leads on Ember.
Icons: M. (Manifesto), sunrise (Daily), compass (Tools), rising steps (Discipline),
candle (Truths), open book (Journal), mirror (Identity).
`preview-row.png` shows the row as it looks on the profile in light and dark mode.
Instagram only lets covers be changed by hand: Profile > hold a highlight > Edit highlight > Edit cover.
Rebuild: `python3 build_highlights.py`.
