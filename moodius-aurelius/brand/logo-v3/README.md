# Moodius Aurelius logo options v3: warm, in the current page shades

Same shades as the page today (Slate #1B1F24, Graphite #2A2F36, Charcoal #3A4049,
Bone #F3EFE7, Ash #B8B3A9, Ember #C9742E), with warmer Stoic motifs.
Outlined SVG + PNG in svg/ and png/; `comparison.png` shows all four.

| Option | Idea |
|---|---|
| A Painted Porch | The Stoa Poikile, the painted porch the Stoics are named after; four painted columns |
| B Olive and Ink | Italic signature-style name with an olive sprig (the tree of Athens) |
| C Ember Point | Today's "M." sharpened, with the Ember full stop |
| D Reading Room | An arch, like a porch opening or a library window, framing the M |

Rebuild: `python3 build_logos.py` (uses ../logo-v2 helpers and fonts).
