# Addis & Mahalik (2003): Contexts of men's help-seeking

**Finding:** Men's help-seeking depends on context: whether a problem feels normal, central to identity, reciprocal, and whether others like them seek help.

**Caveat:** Review; framework rather than one finding.

**Angle:** Men ask for help more when it feels like a trade between equals. So make it one.
