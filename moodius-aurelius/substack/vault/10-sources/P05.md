# Søren Kierkegaard (1849): Despair as not willing to be oneself

**Finding:** Despair includes not willing to be oneself and, in defiance, willing to be oneself on one's own terms.

**Caveat:** English translations still in copyright: 'Idea: ... Moodius words', never a quote.

**Angle:** The quietest despair is wanting to be anyone but you.
