# Moodius engine v2: research and creation (21 Oct 2026)

Surafel's "Content research & creation engine" brief, sections 1–5. Sections 6 onward (stories, carousels, photo dumps…) were cut off in the message and are still to come. This builds on `../reels-engine/` (formats R1–R5, 20 scripts, `engine.py`) and `../strategy/` (Phase 1), and replaces neither.

| File | Section | What's in it |
|---|---|---|
| `01-brand-identity.md` | 1 | Editorial identity, voice, the four evidence tiers, mapping of the original categories to live highlights, 5 improvements |
| `02-research-library.csv` + `02-research-method.md` | 2 | 61 entries (37 empirical, 15 philosophical, 3 house positions, 6 cultural), each with source, year, tier, credibility, key finding, caveat, angle, format, verification |
| `03-accounts-and-formats.md` | 3 | 28 accounts beyond Stoic pages, 10 creative principles, 10 formats scored. No invented metrics |
| `04-pinterest-library.md` + `../pinterest/inspiration/` | 4 | 11 secret research boards, `library.csv`, `inspo.py` (API import, link import, palette scan) |
| `05-reel-formats-A-F.md` + `../reels-engine/scripts/formats-AF.json` | 5 | Six formats with timings, shots, type, audio, captions, export; one rendered sample each; tool verdicts |

Renders: `../reels-engine/renders/A01…F01-*.mp4` (+ cover and caption file). Engine: `../reels-engine/tools/engine.py` v1.2.

## Limits, stated plainly
- Instagram, Pinterest, Reddit, Gutenberg and Wikisource can't be reached from this container. Research used web search. Account formats are described from public coverage, not from reading posts.
- "Canonical citation" rows still need the paper checked before any number goes on screen.
- Pinterest's official MCP server was announced on 22 Sep 2026 (ads-focused). Its setup page couldn't be opened from here.
