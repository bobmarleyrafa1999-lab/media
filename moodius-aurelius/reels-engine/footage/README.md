# Footage for the V2 look (optional)

Shoot once, reuse for months. Phone on a surface (locked-off, no handheld shake), vertical, 4K or 1080p, 10–15 seconds each, low light, **no faces, no logos, no other people's screens**. Name each file `<tag>-<n>.mp4` and drop it in this folder (or upload it to the project and say which tag it is).

| Tag | Shot | Used by |
|---|---|---|
| phone-table | Your phone face up on a table at night, screen dark, a lamp in the background | R003 |
| commute | Train or bus window at dawn or dusk, outside moving | R002 |
| empty-room | A chair by a window, nobody in it | R007 |
| aisle | A shop aisle or the inside of a fridge, soft focus | R008 |
| stairs | Feet climbing a stairwell, from behind | R015 |
| hallway-night | A dark hallway, or a hand placing a phone face down | R020 |
| two-cups | Two mugs on a table | R005 (optional) |
| window-rain | Rain on a window | spare |

The engine desaturates every clip and lays Slate over it at 72%, so exposure doesn't need to be perfect. Clips loop if they're shorter than the reel.
